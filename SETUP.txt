2. Activate: source .venv/bin/activate (Mac/Linux)
3. Install: pip install -r requirements-backend.txt
4. Copy .env.example to .env and set OPENAI_API_KEY.
5. Until Lokesh's retrieval code is ready, set MOCK_RETRIEVAL=true in .env.
6. Run: uvicorn backend.main:app --reload
7. Visit http://127.0.0.1:8000/docs to test GET /companies and POST /chat.
8. For real demo, set MOCK_RETRIEVAL=false and ensure `retrieval.retrieve(company_id, question, k=6)` exists.
